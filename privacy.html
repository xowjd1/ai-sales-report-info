AI Sales Daily Report

Privacy policy

Effective September 20, 2026.

AI Sales Daily Report is a personal automation operated by xowjd1. It processes only the operator's connected accounts and is not open to public registration.

Access and purpose

The tool requests the Google Gmail read-only scope to confirm the connected account and retrieve Fiverr and itch.io notification emails. This scope technically permits mailbox-wide reading, but application searches are limited to those senders. Message headers, notification content, and any explicitly selected transaction reports are used only to verify product sales and prepare reports for the operator. Receipt time is not automatically treated as transaction time. Gmail send, modification, and deletion scopes are not requested.

Storage and service providers

OAuth client credentials and a refresh token are stored in the operator's private GitHub repository using GitHub Actions Secrets. Google provides Gmail data and authorization; GitHub-hosted runners perform the configured collection. Original message contents are processed in execution memory and are not intentionally retained in files, execution logs, public pages, or Discord messages. Connection checks may retain aggregate message counts and success or failure status in private workflow summaries.

When reporting is enabled, only validated product-level summaries are sent to the operator's chosen Discord webhook. Customer email addresses and raw email contents are not included. This tool does not sell Google user data, use it for advertising, or train general-purpose AI models with it.

Retention and control

Original email remains in Gmail according to the account owner's settings. The operator can revoke the app's access in Google Account third-party connection settings, remove the GitHub Secret, disable workflows, and delete stored workflow summaries or Discord reports through those services. Credentials are retained until the operator removes them or authorization expires or is revoked.

Google API data use

AI Sales Daily Report's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

The operator's public contact entry point is the xowjd1 GitHub profile. The Google consent screen also displays the operator's support address.
